Gallery Data API

A tiny read-only API exposing the photo gallery manifest for indukto.eu.

GET /photos.json

Returns the gallery manifest as JSON.

{
  "photos": ["01-sunset.avif", "..."]
}

Each entry is a filename served under https://indukto.eu/photos/, listed in display order.

Machine-readable description

The OpenAPI 3.1 specification for this API lives at /openapi.json. It is discoverable via the API catalog at /.well-known/api-catalog (RFC 9727).
